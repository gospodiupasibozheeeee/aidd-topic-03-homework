## Результат

Приложение запускается, применяет миграции и обслуживает HTTP-запросы. Сохранены
каталог, карточка с графиком, регистрация и сессии, HTML CRUD, REST API, Django
Admin, импорт и фоновое обновление котировок. Доменные функции задания №4
(портфели, уведомления, стратегии, локальная история цен) не добавлялись.

В текущем окружении запущен сервер на <http://127.0.0.1:8011/> с локальной SQLite
БД. Каталог исходно пуст; реальные акции загружаются командой `add_shares` после
настройки токена. Команды повторного запуска приведены в [README.md](README.md).

Интервал постановки задачи **10 секунд** сохранён как фактическое значение
исходной версии, вынесен в настройку; вводящее в заблуждение имя расписания
заменено. Истёкшие сообщения не копятся бесконечно в очереди.

При фоновом обновлении `updated_at` отражает время котировки, при обычном
редактировании модели — время сохранения. Отдельная история котировок не добавлена.
Миграция не восстанавливает дробную часть, уже потерянную старым кодом.
Предварительное предположение анализа о миграционном расхождении `blank=True`
у `auto_now` не подтвердилось: Django выставляет этот параметр автоматически.

Интеграционный сценарий запускает настоящий Django HTTP-сервер, Worker, Beat и
Redis-брокер, импортирует инструменты дважды, дожидается фоновой записи цены,
строит реальный Plotly-график, проверяет отказ поставщика, регистрацию,
автоматический вход, API create/PATCH, CSRF, подтверждение и удаление через HTML,
404 удалённой записи, выход и повторный вход. Рынок в нём представлен **локальным
синтетическим HTTP-сервисом** с документированной формой ответов; реальные
котировки и действующий брокерский токен не использовались.

Доступ к настоящему T‑Invest API остаётся единственной непроверенной внешней
интеграцией: токен в окружении отсутствует. Контракт, тайм-ауты, TLS-настройки,
точность и обработка ошибок проверены с управляемым поставщиком. Для реальных
данных задайте `TINKOFF_TOKEN` в `.env`, при необходимости доверенный CA bundle,
перезапустите процессы и выполните `python manage.py add_shares`.
