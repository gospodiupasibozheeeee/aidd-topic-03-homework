## 1. Быстрый старт (Локальная разработка)

### 1.1. Настройка окружения
1. Создайте файл `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```
2. По умолчанию настроена база данных **SQLite** (`DJANGO_DB_ENGINE=sqlite`), что позволяет запускать приложение локально без Docker.
3. При необходимости укажите `TINKOFF_TOKEN` для загрузки котировок из Т-Банк Инвестиций.

### 1.2. Установка зависимостей и миграции
```bash
pip install -r requirements.txt
python manage.py migrate
```

### 1.3. Запуск тестов
```bash
python manage.py test
```

### 1.4. Запуск сервера разработки
```bash
python manage.py runserver
```
Приложение доступно по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 2. Запуск с PostgreSQL и Redis (Docker)

Если установлен Docker, сервисы СУБД и брокера сообщений запускаются командой:
```bash
docker-compose up -d
```
В файле `.env` установите:
```ini
DJANGO_DB_ENGINE=postgresql
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
CELERY_BROKER_URL=redis://127.0.0.1:6379/0
```

## 5. Основные эндпоинты

### Каталог и карточки акций
- `/` — Главная страница (каталог акций с пагинацией)
- `/<pk>` — Карточка акции с историческим графиком, аналитикой динамики и быстрыми сделками
- `/shares/<pk>/history/` — Полная история изменения рыночных цен и динамика
- `/create` — Форма добавления акции (требуется вход)
- `/user/login/` (а также `/userlogin/`) — Авторизация
- `/user/registration/` (а также `/userregistration/`) — Регистрация

### Новая функциональность (Задание №4)
- `/portfolio/` — Виртуальный инвестиционный портфель (позиции, баланс, PnL)
- `/portfolio/trade/` — Исполнение сделок покупки/продажи акций
- `/watchlist/` — Персональный мониторинг акций и установка целевых ценовых уровней
- `/notifications/` — Журнал уведомлений о достижении целевых уровней
- `/strategies/` — Симулятор алгоритмических инвестиционных стратегий
- `/strategies/<pk>/` — Детальный просмотр стратегии, метрики и лог симуляции

### REST API v1
- `/api/v1/shares/` — CRUD для работы с акциями
- `/api/v1/price-history/` — Архив исторических котировок
- `/api/v1/watchlist/` — Персональный список наблюдения
- `/api/v1/notifications/` — Уведомления пользователя
- `/api/v1/portfolio/my/` — Данные портфеля
- `/api/v1/strategies/` — Инвестиционные стратегии

- `/admin/` — Панель администрирования Django (все модели зарегистрированы)
